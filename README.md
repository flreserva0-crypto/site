# Site Roleplay para GitHub Pages

## Editar o servidor
Abra `scripts/main.js` e altere o objeto `CONFIG`.

## Publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`, `styles/`, `scripts/` e `README.md`.
3. Vá em Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha `main` e `/ (root)`.
6. Salve.
